1. Copy the environment file and rename it to `.env`:

2. No need to change any variables.
⚠️ Note: This setup is for local demo only and not intended for production use.

3. Start the containers:

```bash

```

4. Access the site:

http://test.localhost:8080

5. Log in with username "Administrator" and the password set in `.env` (default: "admin")
